# Source: *From the Remaining Action to the Forces on a Task*

Series made from this source copy `explainer.html`, `code/` and `data/` unchanged (`tools/series.py start`) and
record the explainer's hash.

| Path | Contents |
|---|---|
| `explainer.html` | The document: 20 sections, 94 numbered equations, 7 figures. Generated by `build/`: do not edit it by hand |
| `build/` | Its sources: `src/part0-9.html` (text, `SEC()`/`EQ()` tokens), `head.html`, `tail.html`, `refs_fragment.html`, `fig1-7.svg` |
| `code/` | The scripts behind every number and figure: `checks.toml`, `README.md` (script to section), `logs/` of the last run |
| `data/` | The arm runs the episodes animate, exported by `export_arm.py` from `code/note/sec8_arm/closedloop.py` |

From the repository root:

```bash
python3 sources/variational-whole-body-control/build/build.py sources/variational-whole-body-control/explainer.html
```

```bash
.venv/bin/python tools/run_code_checks.py sources/variational-whole-body-control
```

```bash
python3 tools/check_source.py sources/variational-whole-body-control
```

After a change, rebuild and re-run the checks. If the plans still hold, `python3 tools/series.py rehash
series/<slug>` records the new hash; otherwise plan again with `/plan-series`.
