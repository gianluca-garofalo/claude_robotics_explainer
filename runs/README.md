# runs/

One folder per local pass through the pipeline, named `YYYY-MM-DD-<topic-slug>` (created as `YYYY-MM-DD-scouting`
and renamed after the topic is selected). Contents are git-ignored by default; see `.gitignore` to change that. Runs
made by the scheduled workflow live in its artifacts (`run-final`, 90 days) and, once published, on the `gh-pages`
branch.

```
runs/2026-11-02-<slug>/
├── run.json            run date, focus, search window
├── sources.json        scout: candidate topics with primary sources and claim status
├── scores.json         ranker: judged scores with reasons and cited sources
├── search.json         search demand and supply gap with their evidence (tools/search_demand.py)
├── ranking.md / .json  generated by tools/rank_topics.py
├── episode.json        series mode instead of the four files above (tools/series.py start)
├── selection.json/.md  automatic topic selection with its reasons (tools/auto_select.py), or
├── approval.json       written only by the user's /approve-topic (hook), in human mode
├── draft/              writer: meta.json, outline.md, NN-name.html parts
├── references.json     bibliography with verification records
├── code/               scripts behind every number and figure, checks.toml, README.md, figures/, logs/
├── explainer.html      generated by tools/build_explainer.py
├── review/             reviewer reports, verify/ verdicts, summary.md, render check, gates.md, package.md,
│                       design/<stage>/ (design and reading-time checks, frames, contact sheets), video/ (video
│                       design review)
└── video/              storyboard.md, scenes/, data/, plan.json, checks/, voice/, renders/, final/, README.md
```

`python3 tools/run.py status runs/<run>` shows what is done, stale or next.
